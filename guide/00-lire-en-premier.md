# Lire en premier

Ce dossier `guide/` explique comment Ababacar travaille et comment démarrer un projet Next.js à partir de zéro. Il est écrit pour quelqu'un qui connaît déjà HTML/CSS mais qui n'a jamais utilisé de framework JavaScript.

## Comment lire ces fichiers

Dans l'ordre :

1. `01-prerequis.md` — vérifier que tout est installé, créer le projet
2. `02-architecture.md` — comprendre comment un projet Next.js est organisé
3. `03-pages-et-routing.md` — comprendre comment créer des pages
4. `04-methode-de-travail.md` — comment on avance concrètement sur un projet (dont l'usage de l'IA pour écrire le code)
5. `05-glossaire.md` — tous les mots techniques expliqués simplement (Node, npm, Tailwind, composant, props...). **Garde-le ouvert à côté** pendant que tu lis les autres fichiers, dès qu'un mot n'est pas clair, il y est probablement.

## Le principe important

Tu n'as pas besoin de mémoriser la syntaxe React/Next par cœur. Le but de ces fichiers, c'est que tu comprennes :
- **le vocabulaire** (composant, page, route, props...)
- **où les choses vont** (quel fichier fait quoi)
- **comment demander le bon code à une IA** (Claude, ChatGPT...) sans te tromper de dossier ou casser la structure

Le code lui-même, dans la majorité des cas, tu peux le faire générer par une IA — mais il faut savoir où le coller et pourquoi, sinon ça part vite dans tous les sens. C'est exactement ce que ces fichiers t'apprennent.
